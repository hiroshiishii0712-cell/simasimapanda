# 新Kidsパレット デザインシステム ショーケース

Cowork artifact `kids-palette-examples` の完成版を Git で永続化したものです。
新Kidsパレット (Cinnamoroll 空色 × Kuromi ラベンダー × ダスティピンク) を、
子どもの生活 8 シーンへ同一トーンで体系適用したデザインシステムのショーケースです。

## 開き方

`index.html` をブラウザにドラッグ & ドロップで開く(self-contained・外部依存なし)。

```sh
# もしくはローカルサーバ経由
python3 -m http.server 8000   # http://localhost:8000/kids-palette-examples/
```

## 構成 (8 シーン + リファレンス 2 種)

| 区分 | シーン |
|---|---|
| 学習 | 漢字ドリル(彩月・小4) / 計算ドリル(彩空・小1) |
| 家族・生活 | 今週のミッション / シール台紙(ごほうび) |
| クリエイティブ・記録 | お絵描き準備 / 読書記録カード |
| スケジュール・まとめ | 1日のながれ(時間割) / 自由研究テンプレ |
| 最上部 | パレットリファレンス(6色 × HEX × 役割) |
| 最下部 | 配色クロスリファレンス表(色 × 役割 × 使用シーン × 避ける使い方) |

## 配色トークン

| トークン | HEX | 役割 |
|---|---|---|
| `--p-blue` | `#7AB8D9` | 集中・学習・知識 |
| `--p-lav` | `#A899D1` | 章立て・想像・落ち着き |
| `--p-pink` | `#E89BB5` | 注目・ヒント・誤答 |
| `--p-mint` | `#8BC8B8` | 達成・正解・健康 |
| `--p-lemon` | `#F2D984` | 報酬・ポイント・楽しさ |
| `--p-text` (INK) | `#3B4252` | 本文・線・縁取り |

各色に dark / light 階調を用意。`--*-dark` は中明度背景上のテキスト用、
`--*-light` は大面積背景用。`--p-pink-dark` は `#8C4A5F` (WCAG AA 4.5:1 確保のため初稿から調整)。

## 品質ゲート

- WCAG 2.1 AA: 主要組合せで 4.5:1 以上(大文字 bold は 3:1 適用)
- タッチ領域: インタラクティブ要素 ≥ 44×44px
- 最小フォント: 子ども操作要素 ≥ 16px
- SVG アイコンは全て `aria-hidden="true"`
- レスポンシブ: 860px 未満で 1 カラム表示
